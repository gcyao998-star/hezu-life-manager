# 合租生活管家插画资产

本目录为网页 Demo 的第一批插画资产，采用统一的“精致绘本线条”方向生成。

## 风格基准

- 精细的深海军蓝手绘轮廓；
- 平涂水粉质感和轻微丝网印刷／纸张纹理；
- 燕麦奶油、灰调海军蓝、陶土橙、橄榄绿和浅奶油黄；
- 温暖、成熟、有生活感，不做低龄儿童画；
- 插画负责情绪和辨识度，文字、金额、状态与按钮由真实网页 UI 渲染。

## 生成提示词摘要

所有素材使用同一风格提示词：高品质现代绘本式点状插画、精细深蓝手绘线条、平涂水粉色块、轻微纸张纹理、成熟温暖且不过度低龄。透明贴纸要求主体轮廓完整、四周留白、无文字、无品牌、无水印，可在移动端 96～180px 范围内保持辨识度。

各素材的主体提示分别为：

1. 带厨房、两口锅、浴室、洗衣区和客厅的合租房剖面；
2. 家庭账单、硬币与计算器组成的 AA 费用图形；
3. 卫生间垃圾桶、垃圾袋、清洁刷和循环箭头；
4. 滚筒洗衣机、时钟和空白日历组成的预约图形；
5. 卫生纸、洗洁精、垃圾袋和购物篮组成的公共物品图形；
6. 四名地位平等的青年室友共同拿着房屋钥匙；
7. 公寓楼、带水滴／灯泡图形的账单与确认标记；
8. 三名室友头像、带勾选项的木质公约板和钢笔。
9. 小尺寸账单列表专用插画：电费单＋灯泡插头、洗洁精＋厨房纸＋垃圾袋、路由器＋网络账单。

## 使用约定

- 不在图片中写入正式中文，避免生成文字错误；
- UI 文本、数字和交互状态一律由 HTML/CSS 渲染；
- 首页主场景建议延迟加载之外的功能贴纸按页面按需加载；
- 正式实现时使用 `object-fit: contain`，避免裁掉线稿边缘；
- 不直接在图片文件上覆盖修改，后续版本使用 `-v2`、`-v3` 等后缀。
